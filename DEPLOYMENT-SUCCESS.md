## 🆘 TROUBLESHOOTING

### Website Not Loading:

**Check**:
1. Vercel deployment status (vercel.com/dashboard)
2. DNS propagation (may take a few minutes)
3. Clear browser cache (Ctrl+Shift+Delete)
4. Try incognito/private browsing
5. Test on different device/network

### Images Not Showing:

**Check**:
1. Images are in correct folders
2. File paths are correct (case-sensitive)
3. Images committed to Git (`git status`)
4. Deployment completed successfully
5. Clear browser cache

### Mobile Menu Not Working:

**Check**:
1. JavaScript loaded (check browser console F12)
2. Test on different mobile browser
3. Clear cache on mobile
4. Check for JavaScript errors

### Facebook Preview Not Showing:

**Fix**:
1. Use Facebook Debugger: https://developers.facebook.com/tools/debug/
2. Enter your URL
3. Click "Scrape Again"
4. Wait a few seconds
5. Try sharing again
